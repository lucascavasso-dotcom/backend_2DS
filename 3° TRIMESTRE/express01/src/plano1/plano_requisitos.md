# Plano de Levantamento de Requisitos - Website Institucional

Este documento apresenta o planejamento conceitual e o levantamento de requisitos para a estrutura do website, mapeando o conteúdo e os objetivos de cada uma das páginas solicitadas.

---

## 💻 Visão Geral do Projeto
* **Estilo Visual:** Layout moderno, responsivo (focado em Flexbox/Grid) e adaptável para dispositivos móveis.
* **Identidade Cromática (Placeholders):** 
  * Cor Primária: `[COR]` (Elementos de destaque e botões de ação)
  * Cor Secundária: `[COR]` (Componentes de suporte, cartões e blocos de conteúdo)
  * Fundo: `[COR]` (Fundo de página principal)
  * Texto: `[COR]` (Tipografia principal de alta legibilidade)
* **Elementos Globais:**
  * **Cabeçalho Fixo:** Navegação persistente com links para `/`, `/produtos`, `/sobre` e `/contato`.
  * **Rodapé:** Direitos autorais e links para redes sociais fictícias.
